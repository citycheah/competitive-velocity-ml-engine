1 The Core Statistical Problem: Scale & Maturity Confounding

In competitive media analytics, directly predicting raw engagement metrics (such as 30-day views or likes) suffers from two fatal machine learning biases:

❌ 1. Scale Confounding (Subscriber Memorization)

Raw views correlate > 0.85 with subscriber count. A standard gradient boosted tree or neural network will simply learn to rank high-subscriber channels at the top, completely failing to detect viral breakout moments for mid-tier or emerging competitors.

✓ Solution: Channel-normalized Rolling 30-Day Z-Score Target.
❌ 2. Maturity Bias (Look-Ahead Leakage)

Historical videos have accumulated 100% of their lifetime views, whereas newly published videos have zero. Training on post-upload signals leaks future information into the model's feature matrix $X$.

✓ Solution: Absolute t0 quarantine validator + strictly bounded SQL lag windows.

Milestone 2 Deliverables: dbt Feature Store & Target Formulation

A multi-layered dbt feature store compiled for both local offline DuckDB (data/feature_store.duckdb) and Google Cloud BigQuery.

Mathematical Formulation of Target

1. Weighted Engagement Composite: E = Views_30d + (10 × Likes_30d) + (20 × Comments_30d)
2. Log-Transformed Engagement: E_tilde = ln(1 + max(0, E))
3. Channel-Specific Rolling 30-Day Z-Score: Z_i = (E_tilde_i - μ_channel,30d) / (σ_channel,30d + 0.0001)
4. Binary Supervised Target: is_breakout = 1 if Z_i ≥ 1.0 else 0 (Empirical top ~15% performance)

Model Hierarchy & Bounded SQL Windows

models/staging/stg_youtube_videos.sql & stg_youtube_channels.sql
Materialized as views. Projects intrinsic attributes knowable at $t_0$ (duration, is_short, publish timestamp, title length) and preserves quarantined mature realizations with safe type conversions (DOUBLE).
models/intermediate/int_video_cadence.sql
Computes cadence signals strictly using preceding windows:
  • channel_upload_blitz_24h: count in RANGE BETWEEN 86400 PRECEDING AND 1 PRECEDING
  • channel_upload_blitz_7d: count in RANGE BETWEEN 604800 PRECEDING AND 1 PRECEDING
  • hours_since_last_upload: cold-start imputed to 720.0 hours (30 days)
models/intermediate/int_channel_rolling_stats.sql
Computes rolling trailing 30-day baseline statistics (AVG, STDDEV_SAMP) using RANGE BETWEEN 2592000 PRECEDING AND 1 PRECEDING. Features robust fallback to lifetime baselines if 30-day upload count < 3.
models/marts/fct_video_features_t0.sql
Materialized as a table. Unifies t0 features, joins channel metadata via defensive LEFT JOIN, computes the final $Z$-score, and flags is_breakout.
